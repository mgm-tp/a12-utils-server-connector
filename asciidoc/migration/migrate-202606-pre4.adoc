=== 2026.06-pre4

==== utils-connector-client

===== Breaking Changes

====== Custom Headers Merging

* Custom headers provided via `customHeaders` in `RestRequestPayload` are now **merged** with the default headers (`Content-Type` and `Accept`) instead of replacing them.
* If a custom header has the same key as a default header (e.g., a custom `Content-Type`), the custom value takes precedence.
* Custom headers with undefined values (e.g., `["headerName"]` without a second element) now act as removal signals — the header will be excluded from the final request, even if it was set by a default header.
* **Migration**: If your code was manually adding `Content-Type: application/json;charset=utf8` and `Accept: application/json` to `customHeaders` to work around the previous replacement behavior, you can now remove those entries. They will be provided automatically by the Server Connector unless explicitly overridden.
